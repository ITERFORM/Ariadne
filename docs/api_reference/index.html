This reference is generated from the codebase, not written alongside it: the source carries no doc-comment blocks, so the reference is the symbol inventory — every class, member, free function, template, enum and source file gets a page, private and static state included. The scope is the harness itself; tests/, examples/, skills/, the installer and build artefacts are excluded.

What it covers

  • agent — the harness loop: prompt assembly, tool dispatch, planning, the tape and rebase logic, the TUI front-end.
  • tools — the tool registry and the gateway that serves it (MCP): argument schemas, invocation, approvals.
  • doctor — the local inference stack manager: model fetch and load, the health probe on host:port, the thread policy for the MoE profile, the never-two-models guard.
  • bench — spec-bench: the runner, its configuration, the metrics it emits.
  • mazemaker — the memory backend: the maze graph, recall and rerank, the encrypted store.

Regenerating

The build takes a few seconds for the whole scope and writes only into api/; this landing page is never touched, so hand-written copy and generated reference cannot overwrite each other.

./docs/generate_docs.sh
# config: Doxyfile at the repo root (Doxyfile.default keeps the stock 1.9.8 config for diffing)
# output: docs/api_reference/api/   (1605 .html + 1045 .js incl. search chunks + 47 class PNGs, ~35 MB)
# then:   python3 -m http.server 8080 --directory docs   # http://localhost:8080/api_reference/

Theme

The generated pages carry the site's dark theme: a dark base from HTML_COLORSTYLE=DARK plus assets/ariadne-docs.css, which the generator copies into the output once and links after doxygen.css, so it wins the cascade. One 11 KB sheet is shared by all 1605 pages — the cost of restyling is one file, not one per page. The landing page links the same sheet and adds a local block of its own for the hand-written elements (.card, .meta); no generated page was rewritten to restyle it.

Conventions

  • Extract everything — statics and file-local helpers are documented, because the file-Local Entities index is the harness's most useful map.
  • Source browsing is on — each page links back to the file it came from, with line references resolved in the browser via .md5 manifests and sourcemap.
  • Internal state is visible — private and protected members appear in class pages; access control in declarations stays as written.
  • No graphviz dependency — HAVE_DOT=NO, so no call graphs, no include graphs, no LaTeX, no RTF/MAN/XML. What does ship is doxygen's own dot-free renderer: 47 class/struct inheritance PNGs, 34.7 KB in total — 0.1% of the tree, and the cheapest possible map of the harness's inheritance, so it stays on.
  • Extensions are treated as names — .cc is registered as a source extension so nothing is silently skipped.
  • Nothing is fabricated — no preprocessor expansion, so what you read is the source, not macro-expanded code.
